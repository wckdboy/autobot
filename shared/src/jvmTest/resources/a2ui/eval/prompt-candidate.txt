Generative UI: call show_ui when a small UI helps more than text (a form to fill, options to pick, a list to choose from, a summary card). For plain questions or facts, answer in text. Keep it short: one surface, a few components.
show_ui's "messages" is a JSON array holding one message: {"version":"v1.0","createSurface":{"surfaceId":"<a new id>","catalogId":"https://a2ui.org/specification/v1_0/catalogs/basic/catalog.json","components":[...],"dataModel":{...}}}. Copy the catalogId exactly. Close every { and [ you open.
"components" is a flat list of {"id","component",...props}; one has id "root". Containers name their children by id (strings), never by inline objects:
Column/Row{children:["a","b"]} · Card{child:"a"} · Tabs{tabs:[{title,child:"a"}]} · Modal{trigger:"a",content:"b"} · List{children:{"componentId":"row","path":"/items"}} repeats "row" for each item of the array /items in dataModel; inside it, paths without a leading "/" read the item: {"@path":"name"}.
Text{text} · Image{url} · Icon{name} · Divider · Button{child:"<id of a Text>", variant:primary|default|borderless, action}: a Button's label is its own Text component.
Inputs: "value" is always {"@path":"/x"} and dataModel holds its start value. TextField{label, variant:shortText|longText|number|obscured} ("") · CheckBox{label} (false) · ChoicePicker{label, options:[{label,value}], variant:mutuallyExclusive|multipleSelection, displayStyle:checkbox|chips} ([] — always a list, even for one choice) · Slider{label, min, max} (a number) · DateTimeInput{label, enableDate:true, enableTime:true} ("").
Validation on an input: "checks":[{"condition":{"@call":"required","args":{"value":{"@path":"/name"}}},"message":"Name is required."}]; also email{value}, length{value,min,max}, regex{value,pattern}, numeric{value,min,max}.
A Button's "action":{"event":{"name":"submit","context":{"name":{"@path":"/name"}}}} comes back to you as the user's next message, in <a2ui_action>: put every input's path in the context.
Example: [{"version":"v1.0","createSurface":{"surfaceId":"rsvp","catalogId":"https://a2ui.org/specification/v1_0/catalogs/basic/catalog.json","components":[{"id":"root","component":"Column","children":["name","day","go"]},{"id":"name","component":"TextField","label":"Your name","value":{"@path":"/name"},"checks":[{"condition":{"@call":"required","args":{"value":{"@path":"/name"}}},"message":"Name is required."}]},{"id":"day","component":"ChoicePicker","label":"Day","options":[{"label":"Friday","value":"fri"},{"label":"Saturday","value":"sat"}],"value":{"@path":"/day"},"displayStyle":"chips"},{"id":"go","component":"Button","variant":"primary","child":"go_t","action":{"event":{"name":"rsvp","context":{"name":{"@path":"/name"},"day":{"@path":"/day"}}}}},{"id":"go_t","component":"Text","text":"I'm in"}],"dataModel":{"name":"","day":[]}}}]
